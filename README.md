# ভেষজ উন্নয়ন ফাউন্ডেশন — বাংলা PHP Website

Responsive বাংলা PHP website with Admin Panel and content management modules.

## Features
- Responsive Bangla homepage
- Admin dashboard
- Notice Board add/delete/publish
- Donation submission + admin approval
- Member registration + admin approval
- Gallery upload/delete
- SQLite database auto-setup

## Admin
URL: `/admin/login.php`

Initial credentials:
- Username: `admin`
- Password: `admin123`

Change the default password before production use.

## Requirements
- PHP 8+
- PDO SQLite enabled
- Writable `database/` and `uploads/` directories

## Public pages
- `/index.php`
- `/notices.php`
- `/donate.php`
- `/member-register.php`
- `/gallery.php`

This project is prepared for deployment to `vesojunnayanfoundation.com`.
